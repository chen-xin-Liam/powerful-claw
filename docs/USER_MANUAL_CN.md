# 用户手册

## 概述

AI 计算机控制是一款人工智能驱动的自动化应用程序，允许您使用自然语言命令来控制您的计算机。

## 入门指南

### 1. 启动应用程序

```bash
python src/ui/customtkinter_app.py
```

或者使用主入口：

```bash
python src/main.py
```

### 2. 设置权限级别

在侧边栏中，选择适当的权限级别：

- **None**：仅查看，无系统控制权限
- **View**：与 None 相同
- **Limited**：允许鼠标移动、点击和键盘输入
- **Full**：所有操作，包括快捷键和窗口控制

### 3. 选择模式

- **聊天模式**：与 AI 进行常规对话
- **控制模式**：AI 可以生成系统操作

## 基本使用

### 聊天模式

1. 在聊天输入框中输入您的消息
2. 点击"发送"或按 Enter 键
3. 查看 AI 的回复

### 控制模式

1. 在侧边栏中切换到控制模式
2. 让 AI 执行任务（例如："打开记事本并输入'Hello World'"）
3. 如果 AI 生成了操作，点击"执行操作"来运行它们

## 可用操作

### 鼠标控制
- 将鼠标移动到特定坐标
- 在当前位置或特定坐标点击
- 从一个位置拖动到另一个位置

### 键盘控制
- 输入文本
- 按下单个按键
- 执行快捷键组合

### 屏幕截图
- 点击侧边栏中的"截取屏幕"来截图

### 摄像头访问
- 点击"切换摄像头"以启用/禁用摄像头

## 示例命令

```
"将鼠标移动到位置 (100, 200)"
"在当前鼠标位置点击"
"在活动窗口中输入 'Hello, World!'"
"按 Ctrl+C 复制"
"打开浏览器并导航到 google.com"
```

## 安全特性

### 故障保护
- 将鼠标移动到屏幕左上角可中止任何正在运行的操作
- 此功能默认启用以确保安全

### 权限控制
- 在执行操作前始终检查权限级别
- 在授予完全控制权限之前，先从受限权限开始

## 使用技巧

1. **具体明确**：为 AI 提供清晰的指令
2. **从小处着手**：在执行复杂操作之前，先从简单任务开始
3. **监控执行**：观察执行日志以获取反馈
4. **谨慎使用**：AI 可能会出错，请始终监督操作

## 键盘快捷键

| 快捷键 | 操作 |
|--------|------|
| Ctrl+C | 复制 |
| Ctrl+V | 粘贴 |
| Ctrl+Z | 撤销 |
| Esc | 取消当前操作 |

## 技术支持

如果您遇到问题或有疑问：
1. 检查执行日志中的错误消息
2. 验证您的 API 密钥是否正确设置
3. 确保已安装所有依赖项
