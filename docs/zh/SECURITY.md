## 报告安全漏洞

**请勿通过公开的 GitHub Issue 报告安全漏洞。**

请通过以下渠道私密报告：

- **GitHub Security Advisories**：[报告漏洞](https://github.com/chen-xin-Liam/powerful-claw/security/advisories/new)
- **邮件**：在仓库中发起带 `security` 标签的私密讨论

### 报告内容建议

1. **漏洞描述** — 漏洞是什么，如何被利用
2. **影响范围** — 攻击者可能造成的后果（数据泄露、代码执行、权限提升等）
3. **复现步骤** — 触发问题的最小步骤或概念验证代码
4. **环境信息** — 操作系统、Python 版本、受影响模块（AI 服务、WebSocket 服务器、MCP 等）
5. **修复建议**（可选）— 如有补丁或缓解方案请一并提供

### 响应时间

| 阶段 | 时间 |
|------|------|
| 确认收到 | 72 小时内 |
| 初步评估 | 7 天内 |
| 修复或缓解 | 视严重程度而定（高危问题优先处理） |
| 公开披露 | 修复合并后，署名报告者（除非要求匿名） |

## 安全模型

### 权限级别

应用程序对 AI Agent 操作实施 **4 级权限模型**：

| 级别 | 能力 |
|------|------|
| **None** | 无屏幕访问权限，无输入模拟 |
| **View** | 仅屏幕捕获，只读 |
| **Limited** | 屏幕捕获 + 受限键鼠操作（排除系统关键区域） |
| **Full** | 完整屏幕访问 + 无限制键鼠操作 |

**默认设置**：`None` — 用户明确启用前，Agent 不执行任何操作。

### 数据处理

- **API 密钥** 存储在本地 `.env` 或 `config/settings.ini` 中，不会传输给第三方
- **屏幕截图** 在本地处理；仅在用户触发 AI 请求时发送给已配置的 AI 提供方
- **对话历史** 存储在本地 `conversations.json` 中，已排除出版本控制
- **局域网集群通信** 使用 Fernet 对称加密（AES-128-CBC）+ RSA 密钥交换

### 网络服务

| 端口 | 服务 | 暴露范围 |
|------|------|----------|
| 15000 | WebSocket（主） | `0.0.0.0` — 局域网可访问 |
| 15001 | WebSocket（备） | `0.0.0.0` |
| 15002 | HTTP API 服务器 | `0.0.0.0` |
| 15003 | WebSocket（API） | `0.0.0.0` |
| 15004 | 屏幕监控 | `0.0.0.0` |
| 15010 | 视频编辑器 | `0.0.0.0` |
| 15012 | 视频编辑器 WebSocket | `0.0.0.0` |

**注意**：这些服务默认绑定 `0.0.0.0` 以支持局域网功能。如不需要远程访问，请通过防火墙规则限制。

### MCP 服务器

MCP 服务器以 **本地子进程** 方式启动，使用 stdio 传输。它们继承应用程序的环境变量（包括 API 密钥）。仅从可信来源导入 MCP 配置。

## 已知安全注意事项

- **桌面自动化**：Agent 可以模拟键鼠输入。恶意提示词或被攻陷的 AI 提供方可能触发非预期操作。建议尽可能使用 `Limited` 权限级别。
- **屏幕捕获**：截图可能包含敏感信息（密码、个人数据）。应用程序在发送给 AI 提供方前不会过滤敏感内容。
- **未验证的 MCP 服务器**：导入的 MCP 服务器与主应用具有相同权限。导入前请审查配置。
- **无沙箱机制**：应用程序以用户完整操作系统权限运行。启用 `Full` 权限模式时请格外谨慎。

---

## 用户最佳实践

1. **优先使用 `View` 或 `Limited` 权限**，除非确实需要完全自动化
2. **不要将端口 15000–15012 暴露到公网** — 使用防火墙限制为仅局域网
3. **API 密钥不要提交到版本控制** — 使用 `.env` 文件（已在 `.gitignore` 中）
4. **导入外部 MCP 配置前先审查**
5. **定期更新依赖** — 运行 `pip install -U -r requirements.txt` 获取安全补丁

## 报告范围

以下属于 **报告范围内**：

- 权限模型中的身份验证/授权绕过
- 通过网络服务的远程代码执行
- 日志或网络流量中的 API 密钥泄漏
- MCP 服务器管理中的权限提升
- 未授权方获取数据（屏幕截图、对话历史、API 密钥）

以下属于 **报告范围外**：

- 第三方依赖中的漏洞（请报告给上游项目）
- 社会工程学攻击
- 物理接触设备
- 需要用户禁用安全功能的问题（如设置为 `Full` 权限）
