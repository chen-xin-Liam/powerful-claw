# AI 库调用工具使用指南

## 📚 概述 

AI 现在可以充分利用项目中安装的所有 Python 库，包括：

- **AI/ML 库**: openai, ultralytics (YOLO), torch, transformers
- **数据处理**: numpy, pandas, scipy, sympy
- **图像处理**: opencv-python, pillow
- **音频处理**: librosa, pydub, sounddevice
- **视频处理**: moviepy, ffmpeg-python, decord
- **文档处理**: python-docx, openpyxl, PyPDF2, pdfplumber
- **可视化**: matplotlib, seaborn, plotly
- **NLP**: thulac, snownlp, gensim
- **网络请求**: requests, aiohttp
- **工具库**: pyautogui, keyboard, pyperclip, rich, loguru
