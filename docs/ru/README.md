> 💡 **Концепция проекта**
> Большинство ИИ-агентов ограничиваются диалогом. Этот проект создаёт локального агента, который **считывает изображение экрана, понимает содержимое интерфейса и управляет клавиатурой/мышью для выполнения задач**.
> Трансляция рабочего стола, видеомонтаж и кластерные вычисления в LAN — вспомогательные модули, часть из которых ещё в разработке.

## ✨ Ключевые возможности

- 🧠 **Локальный агент рабочего стола**: подключение к мультимодальным LLM (Ollama / OpenAI-совместимые / NVIDIA API), обнаружение объектов на экране через YOLO, понимание скриншотов и автоматизация ввода. Встроенная 4-уровневая модель разрешений (None/View/Limited/Full) снижает риск ошибочных действий.
- 📺 **Трансляция рабочего стола в реальном времени**: настраиваемая частота 1–30 FPS, протоколы RTMP/SRT/WebRTC. Компрессия по разнице кадров и блочное кодирование снижают трафик. Просмотр прямо в браузере.
- 🎬 **Встроенный веб-видеоредактор (базовый)**: многодорожечный таймлайн, цветокоррекция, субтитры SRT/ASS, преобразование речи в субтитры. Экспорт в MP4/MOV/GIF/WebM (1080P/2K/4K).
- 🌐 **Планирование вычислений в LAN (WIP)**: автоматическое обнаружение узлов по UDP, сбор нагрузки CPU/памяти/GPU/NPU, планирование задач, шифрование Fernet/RSA. Объединение простаивающих машин в инференс-кластер.
- 🎨 **Подключаемый UI рабочего стола**: две реализации рендеринга — лёгкая на Python (Pillow) и высокопроизводительная на C++/OpenGL с эффектом матового стекла и анимациями.
- 🛠️ **Ядро на Python**: лёгкая архитектура для удобного чтения кода, доработки и локальной отладки.

## 📚 Технологический стек

| Модуль | Технологии | Описание |
|--------|-----------|----------|
| ИИ-агент | Python 3.13+ | Мультимодальные LLM: Ollama/OpenAI/NVIDIA |
| Зрение | Python + YOLOv8 | Захват экрана, обнаружение объектов, высокий DPI |
| Управление ПК | Python (pyautogui/keyboard) | Кроссплатформенная автоматизация, 4 уровня разрешений |
| Видеопоток | Python + FFmpeg | RTMP/SRT/WebRTC, компрессия по разнице кадров |
| UI | CustomTkinter + C++/OpenGL | Матовое стекло/свечение, две реализации |
| Кластер | Python + UDP/шифрование | Обнаружение узлов, планирование, Fernet/RSA |
| Логи/ошибки | Loguru/Rich | Единые коды ошибок, уровни логов, трассировка |
| Математический движок | C++17 + cppyy в Python | 44 типа узлов (арифметика/тригонометрия/LU/статистика), fallback на чистом Python |

## 🐛 Известные проблемы и незавершённые модули

- Погрешность определения координат экрана на дисплеях с высоким DPI
- Периодическое мерцание при смене разрешения дисплея
- Базовая проверка выполнена только на Windows 10/11
- Смена темы изредка может подвешивать UI
- Кластерные вычисления: логика планирования узлов не завершена
- Видеоредактор: готова только базовая архитектура, функции неполные
