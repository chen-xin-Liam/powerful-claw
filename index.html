九大核心功能模块，全方位覆盖 AI 智能控制场景

🤖
AI 智能控制

多 AI 提供者支持，自动轮回对话与系统控制

  • 多 AI 提供者：NVIDIA、OpenAI、Ollama、自定义
  • 自动轮回对话，可设置调用频率限制
  • 鼠标键盘控制、屏幕截图、YOLO 检测
  • 四级权限管理（None/View/Limited/Full）
📺
桌面监控 15004-15009

实时屏幕与音频捕获，多协议自适应传输

  • 1-30 FPS 可调帧率实时捕获
  • 视频：RTMP/SRT/SRTP 协议自适应
  • 音频：WebRTC/SRTP/SMPTE 2110
  • 远程桌面式视频流，低带宽占用
🎬
视频剪辑 15010

多轨道时间轴，专业级剪辑与特效处理

  • 视频/音频/字幕/画中画多轨道
  • 切割、合并、调色、转场特效
  • 语音转字幕，SRT/ASS 导出
  • 1080P/2K/4K，MP4/MOV/GIF/WebM
🎮
RCON 广播 15001

  • 实时控制台信息广播
  • 游戏服务器事件推送

⚡ 快速开始

三步即可启动应用

1

克隆项目

获取项目源代码

# 克隆仓库
git clone <repository-url>
cd ai-computer-control
2

安装依赖

使用 Python 3.11+ 安装所有依赖

# 安装依赖
pip install -r requirements.txt
3

启动应用

Windows 用户推荐使用一键启动脚本

# Windows 一键启动
.\start_app.ps1

# 或手动启动
python src/main.py

🏗️ 项目结构

清晰的模块化目录组织

ai-computer-control/
├── src/ # 源代码目录
│ ├── config/ # 配置管理
│ ├── services/ # 服务层（AI/监控/视频/集群）
│ │ └── cluster/ # 集群服务模块
│ ├── system/ # 系统控制（鼠标键盘/视觉）
│ ├── ui/ # 用户界面
│ │ └── effects/ # UI 视觉特效模块
│ ├── utils/ # 工具模块
│ └── main.py # 主入口
├── docs/ # 文档目录（中英双语）
├── config/themes/ # 主题配置
├── .env.example # 环境变量示例
├── requirements.txt # Python 依赖
├── start_app.ps1 # PowerShell 启动脚本
└── README.md # 项目说明
